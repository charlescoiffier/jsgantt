# jsgantt v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire une bibliothèque JS de diagrammes de Gantt interactifs (drag, resize, dépendances FS/SS/FF/SF, hiérarchie, zoom), rendus en SVG et entièrement stylés par CSS, avec export SVG, JSON et PDF et impression.

**Architecture:** Un noyau pur sans DOM (`dates`, `model`, `scheduler`, `timescale`, calcul de mise en page dans `renderer`) testé avec `node:test`. Un renderer qui transforme la mise en page en SVG (classes CSS, géométrie lue dans des variables CSS), une couche `interactions` par délégation d'événements Pointer, et une façade `Gantt`. Les exports réutilisent le SVG rendu en inlinant les styles calculés.

**Tech Stack:** JavaScript vanilla ES modules (aucun build), CSS, SVG, `node:test` (Node ≥ 20, testé avec 23), svg2pdf.js 2.2.3 + jsPDF 2.5.1 chargés à la demande pour le PDF uniquement.

**Spec:** `docs/superpowers/specs/2026-10-13-gantt-design.md`

## Global Constraints

- JS vanilla en ES modules, **sans build** ni dépendance (sauf PDF : svg2pdf.js + jsPDF, chargés à la demande, optionnels).
- Rendu **entièrement en SVG**, stylé par classes CSS et variables CSS. **Aucune couleur ni taille codée en dur dans le JS** : la géométrie vient de `--gantt-row-height`, `--gantt-bar-height`, `--gantt-table-width`, `--gantt-header-height`, `--gantt-col-width-day|week|month` lues via `getComputedStyle` (les valeurs par défaut dans le JS ne servent que de repli).
- Dates : jours entiers `YYYY-MM-DD`, traités en UTC, **fin incluse**. Granularité = le jour. Jalon = durée nulle.
- Contraintes de lien sur la cible B depuis A : FS `start(B) ≥ end(A) + 1 + lag` ; SS `start(B) ≥ start(A) + lag` ; FF `end(B) ≥ end(A) + lag` ; SF `end(B) ≥ start(A) - 1 + lag`. Planification **en avant seulement** (une tâche n'est jamais avancée).
- Liens vers un groupe : autorisés, appliqués à ses dates agrégées ; si un lien contraint un groupe, tout le groupe est décalé du même delta. Lien entre un groupe et un de ses descendants (dans un sens ou dans l'autre) : rejeté. Cycles (en comptant un groupe comme l'ensemble de ses descendants) : rejetés.
- Classes CSS publiques : `gantt-row`, `gantt-row--alt`, `gantt-bar`, `gantt-bar--group`, `gantt-bar--milestone`, `gantt-progress`, `gantt-label`, `gantt-handle`, `gantt-link`, `gantt-link--fs|ss|ff|sf`, `gantt-today`, `gantt-weekend` ; états `is-selected`, `is-collapsed`, `is-dragging`, `is-invalid`. Chaque tâche porte `data-id` et son `className`.
- Événements : `change`, `select`, `invalid`, `scale`. Option `readonly: true` désactive les interactions.
- Import JSON invalide : exception avec message précis, aucun état partiel. Opérations interdites : refusées avec événement `invalid`.
- Messages d'erreur et libellés en français.
- Tests : `node:test` (`npm test`) sur `dates`, `model`, `scheduler`, `timescale` et la mise en page pure. Rendu/interactions/exports vérifiés dans `demo/index.html`.
- Hors v1 : calendriers ouvrés, chemin critique, planification en arrière, contraintes de dates, navigation clavier complète, tests DOM automatisés, heures, création/suppression de tâches à la souris.

## Review Focus

Entrées que la spec implique sans les nommer, les plus susceptibles de casser, avec le comportement attendu :

1. **Planning vide** (`tasks: []`, ou aucune option) : le modèle, la mise en page et le rendu fonctionnent, affichent un diagramme vide sans exception (testé en Tasks 2 et 6, vérifié visuellement en Task 7).
2. **Import avec une date invalide** (`2026-02-30`, `2026-1-1`) ou fin avant début : exception claire nommant la tâche, jamais un modèle à moitié construit (Task 2).
3. **Frontières de calendrier** : 29 février 2028, changement d'heure d'automne, passage de mois et d'année : les écarts en jours restent exacts (Task 1, Task 5).
4. **Liens dont une extrémité est masquée par un repli de groupe** : la flèche se rattache au groupe replié ; un lien entre deux enfants du même groupe replié n'est pas dessiné (Task 6).
5. **Tâches d'un jour ou jalons à très petite échelle** : la barre reste visible (largeur minimale) et un jalon garde une forme de losange cliquable (Task 6).

```js
const MS = 86400000;

function utc(year, month, day) {
  const d = new Date(0);
  d.setUTCFullYear(year, month, day);
  return d;
}

export function toDay(str) {
  const m = typeof str === 'string' ? /^(\d{4})-(\d{2})-(\d{2})$/.exec(str) : null;
  if (!m) throw new Error(`Date invalide : ${JSON.stringify(str)} (attendu AAAA-MM-JJ)`);
  const [year, month, day] = [Number(m[1]), Number(m[2]) - 1, Number(m[3])];
  const d = utc(year, month, day);
  if (d.getUTCFullYear() !== year || d.getUTCMonth() !== month || d.getUTCDate() !== day) {
    throw new Error(`Date invalide : ${JSON.stringify(str)} (ce jour n'existe pas)`);
  }
  return d.getTime() / MS;
}

export function fromDay(n) {
  return new Date(n * MS).toISOString().slice(0, 10);
}

export function dayOfWeek(n) {
  return new Date(n * MS).getUTCDay();
}

export function ymd(n) {
  const d = new Date(n * MS);
  return { year: d.getUTCFullYear(), month: d.getUTCMonth(), day: d.getUTCDate() };
}

export function dayFromYMD(year, month, day) {
  return utc(year, month, day).getTime() / MS;
}
```

```js
import { toDay, fromDay } from './dates.js';

export const LINK_TYPES = ['FS', 'SS', 'FF', 'SF'];

export class GanttModel {
  #tasks = new Map();
  #children = new Map();
  #links = [];
  #linkSeq = 0;

  constructor(data = {}) {
    const { tasks = [], links = [] } = data;
    if (!Array.isArray(tasks)) throw new Error('"tasks" doit être un tableau');
    if (!Array.isArray(links)) throw new Error('"links" doit être un tableau');
    for (const raw of tasks) this.#loadTask(raw);
    this.#buildHierarchy();
    this.#resolveDates();
    this.#aggregateGroups();
    for (const raw of links) {
      const res = this.addLink(raw);
      if (!res.ok) throw new Error(`Lien ${raw?.id ?? `${raw?.from}→${raw?.to}`} invalide : ${res.reason}`);
    }
  }

  #loadTask(raw) {
    if (!raw || typeof raw !== 'object') throw new Error('Chaque tâche doit être un objet');
    const { id } = raw;
    if (typeof id !== 'string' || id === '') throw new Error('Chaque tâche doit avoir un "id" (chaîne non vide)');
    if (this.#tasks.has(id)) throw new Error(`Identifiant de tâche dupliqué : "${id}"`);
    const progress = raw.progress ?? 0;
    if (typeof progress !== 'number' || !(progress >= 0 && progress <= 1)) {
      throw new Error(`Tâche "${id}" : "progress" doit être un nombre entre 0 et 1`);
    }
    const parse = (key) => {
      if (raw[key] === undefined) return undefined;
      try {
        return toDay(raw[key]);
      } catch (e) {
        throw new Error(`Tâche "${id}" : ${e.message}`);
      }
    };
    this.#tasks.set(id, {
      id,
      name: String(raw.name ?? ''),
      start: parse('start'),
      end: parse('end'),
      progress,
      parentId: raw.parentId ?? null,
      collapsed: raw.collapsed === true,
      milestone: raw.milestone === true,
      className: raw.className ?? '',
    });
  }

  #buildHierarchy() {
    const push = (parent, id) => {
      if (!this.#children.has(parent)) this.#children.set(parent, []);
      this.#children.get(parent).push(id);
    };
    for (const t of this.#tasks.values()) {
      if (t.parentId === t.id) throw new Error(`Boucle dans la hiérarchie autour de "${t.id}"`);
      if (t.parentId !== null && !this.#tasks.has(t.parentId)) {
        throw new Error(`Tâche "${t.id}" : parent inconnu "${t.parentId}"`);
      }
      push(t.parentId, t.id);
    }
    for (const t of this.#tasks.values()) {
      let cur = t;
      let steps = 0;
      while (cur.parentId !== null) {
        cur = this.#tasks.get(cur.parentId);
        if (++steps > this.#tasks.size) throw new Error(`Boucle dans la hiérarchie autour de "${t.id}"`);
      }
    }
  }

  #resolveDates() {
    for (const t of this.#tasks.values()) {
      if (this.isGroup(t.id)) continue;
      if (t.start === undefined) throw new Error(`Tâche "${t.id}" : "start" est requis`);
      if (t.milestone) {
        if (t.end === undefined) t.end = t.start;
        else if (t.end !== t.start) throw new Error(`Tâche "${t.id}" : un jalon doit avoir une fin égale à son début`);
        continue;
      }
      if (t.end === undefined) throw new Error(`Tâche "${t.id}" : "end" est requis`);
      if (t.end < t.start) throw new Error(`Tâche "${t.id}" : la fin précède le début`);
    }
  }

  #aggregateGroups() {
    for (const t of this.#tasks.values()) {
      if (!this.isGroup(t.id)) continue;
      let start = Infinity;
      let end = -Infinity;
      for (const id of this.leafIdsUnder(t.id)) {
        const leaf = this.#tasks.get(id);
        start = Math.min(start, leaf.start);
        end = Math.max(end, leaf.end);
      }
      t.start = start;
      t.end = end;
    }
  }

  get tasks() {
    return [...this.#tasks.values()];
  }

  get links() {
    return this.#links;
  }

  getTask(id) {
    return this.#tasks.get(id);
  }

  childrenOf(parentId = null) {
    return (this.#children.get(parentId) ?? []).map((id) => this.#tasks.get(id));
  }

  isGroup(id) {
    return (this.#children.get(id)?.length ?? 0) > 0;
  }

  descendantsOf(id) {
    const out = [];
    const walk = (parent) => {
      for (const child of this.#children.get(parent) ?? []) {
        out.push(child);
        walk(child);
      }
    };
    walk(id);
    return out;
  }

  leafIdsUnder(id) {
    return this.isGroup(id) ? this.descendantsOf(id).filter((d) => !this.isGroup(d)) : [id];
  }

  ancestorsOf(id) {
    const out = [];
    let parent = this.#tasks.get(id)?.parentId ?? null;
    while (parent !== null) {
      out.push(parent);
      parent = this.#tasks.get(parent).parentId;
    }
    return out;
  }

  visibleRows() {
    const rows = [];
    const walk = (parentId, depth) => {
      for (const t of this.childrenOf(parentId)) {
        rows.push({ id: t.id, depth });
        if (!t.collapsed) walk(t.id, depth + 1);
      }
    };
    walk(null, 0);
    return rows;
  }

  progressOf(id) {
    const t = this.#tasks.get(id);
    if (!this.isGroup(id)) return t.progress;
    let done = 0;
    let total = 0;
    for (const leafId of this.leafIdsUnder(id)) {
      const leaf = this.#tasks.get(leafId);
      const duration = leaf.end - leaf.start + 1;
      done += leaf.progress * duration;
      total += duration;
    }
    return total === 0 ? 0 : done / total;
  }

  checkLink(link) {
    const { from, to } = link;
    if (!this.#tasks.has(from)) return `tâche source inconnue : "${from}"`;
    if (!this.#tasks.has(to)) return `tâche cible inconnue : "${to}"`;
    if (!LINK_TYPES.includes(link.type)) return `type de lien inconnu : "${link.type}"`;
    if (!Number.isInteger(link.lag ?? 0)) return 'le décalage (lag) doit être un entier';
    if (from === to) return 'une tâche ne peut pas être liée à elle-même';
    if (this.ancestorsOf(from).includes(to) || this.ancestorsOf(to).includes(from)) {
      return 'lien interdit entre un groupe et un de ses descendants';
    }
    if (this.#links.some((x) => x.from === from && x.to === to && x.type === link.type)) {
      return 'ce lien existe déjà';
    }
    if (this.#wouldCycle(from, to)) return 'ce lien créerait un cycle';
    return null;
  }

  #wouldCycle(from, to) {
    const expand = (id) => [id, ...this.descendantsOf(id)];
    const adj = new Map();
    const addEdge = (a, b) => {
      for (const x of expand(a)) {
        if (!adj.has(x)) adj.set(x, new Set());
        for (const y of expand(b)) adj.get(x).add(y);
      }
    };
    for (const link of this.#links) addEdge(link.from, link.to);
    addEdge(from, to);
    const state = new Map(); // 1 = en cours, 2 = terminé
    for (const root of adj.keys()) {
      if (state.has(root)) continue;
      state.set(root, 1);
      const stack = [[root, adj.get(root).values()]];
      while (stack.length) {
        const [node, it] = stack[stack.length - 1];
        const next = it.next();
        if (next.done) {
          state.set(node, 2);
          stack.pop();
          continue;
        }
        const n = next.value;
        if (state.get(n) === 1) return true;
        if (!state.has(n)) {
          state.set(n, 1);
          stack.push([n, (adj.get(n) ?? new Set()).values()]);
        }
      }
    }
    return false;
  }

  addLink(link) {
    const norm = { from: link?.from, to: link?.to, type: link?.type ?? 'FS', lag: link?.lag ?? 0 };
    const reason = this.checkLink(norm);
    if (reason) return { ok: false, reason };
    let id = link?.id;
    if (id === undefined) {
      do {
        id = `l${++this.#linkSeq}`;
      } while (this.#links.some((x) => x.id === id));
    } else if (this.#links.some((x) => x.id === id)) {
      return { ok: false, reason: `identifiant de lien dupliqué : "${id}"` };
    }
    const stored = { id, ...norm };
    this.#links.push(stored);
    return { ok: true, link: stored };
  }

  removeLink(id) {
    const i = this.#links.findIndex((x) => x.id === id);
    if (i === -1) return false;
    this.#links.splice(i, 1);
    return true;
  }

  getData() {
    const tasks = this.tasks.map((t) => {
      const o = {
        id: t.id,
        name: t.name,
        start: fromDay(t.start),
        end: fromDay(t.end),
        progress: t.progress,
        parentId: t.parentId,
      };
      if (t.collapsed) o.collapsed = true;
      if (t.milestone) o.milestone = true;
      if (t.className) o.className = t.className;
      return o;
    });
    return { tasks, links: this.#links.map((x) => ({ ...x })) };
  }

  clone() {
    return new GanttModel(this.getData());
  }
}
```

```js
export function computeDates(model) {
  const cur = new Map();
  const leavesOf = new Map();
  for (const t of model.tasks) {
    leavesOf.set(t.id, model.leafIdsUnder(t.id));
    if (!model.isGroup(t.id)) cur.set(t.id, { start: t.start, end: t.end });
  }
  const span = (id) => {
    let start = Infinity;
    let end = -Infinity;
    for (const leaf of leavesOf.get(id)) {
      const c = cur.get(leaf);
      if (c.start < start) start = c.start;
      if (c.end > end) end = c.end;
    }
    return { start, end };
  };

  const links = model.links;
  const limit = (model.tasks.length + 1) * (links.length + 1) + 10;
  for (let pass = 0; ; pass++) {
    if (pass > limit) throw new Error('Planification non convergente (cycle de dépendances ?)');
    let changed = false;
    for (const link of links) {
      const a = span(link.from);
      const b = span(link.to);
      const lag = link.lag ?? 0;
      let delta;
      switch (link.type) {
        case 'FS':
          delta = a.end + 1 + lag - b.start;
          break;
        case 'SS':
          delta = a.start + lag - b.start;
          break;
        case 'FF':
          delta = a.end + lag - b.end;
          break;
        case 'SF':
          delta = a.start - 1 + lag - b.end;
          break;
        default:
          throw new Error(`Type de lien inconnu : "${link.type}"`);
      }
      if (delta > 0) {
        for (const leaf of leavesOf.get(link.to)) {
          const c = cur.get(leaf);
          c.start += delta;
          c.end += delta;
        }
        changed = true;
      }
    }
    if (!changed) break;
  }
  return cur;
}
```

```js
import { dayOfWeek, ymd, dayFromYMD } from './dates.js';

export const SCALES = ['day', 'week', 'month'];
export const DEFAULT_COL_WIDTHS = { day: 28, week: 84, month: 120 };
export const MONTHS_SHORT = ['janv.', 'févr.', 'mars', 'avr.', 'mai', 'juin', 'juil.', 'août', 'sept.', 'oct.', 'nov.', 'déc.'];
export const MONTHS_LONG = ['janvier', 'février', 'mars', 'avril', 'mai', 'juin', 'juillet', 'août', 'septembre', 'octobre', 'novembre', 'décembre'];

export class Timescale {
  constructor({ scale = 'week', colWidths = {}, originDay, endDay } = {}) {
    if (!SCALES.includes(scale)) throw new Error(`Échelle inconnue : "${scale}"`);
    if (!Number.isInteger(originDay) || !Number.isInteger(endDay) || endDay < originDay) {
      throw new Error('Plage de dates invalide');
    }
    this.scale = scale;
    this.originDay = originDay;
    this.endDay = endDay;
    const w = { ...DEFAULT_COL_WIDTHS, ...colWidths }[scale];
    this.pixelsPerDay = scale === 'day' ? w : scale === 'week' ? w / 7 : w / 30;
  }

  get totalWidth() {
    return (this.endDay - this.originDay + 1) * this.pixelsPerDay;
  }

  dayToX(day) {
    return (day - this.originDay) * this.pixelsPerDay;
  }

  xToDay(x) {
    return Math.floor(x / this.pixelsPerDay) + this.originDay;
  }

  barWidth(start, end) {
    return (end - start + 1) * this.pixelsPerDay;
  }

  weekendRects() {
    if (this.scale === 'month') return [];
    const rects = [];
    for (let d = this.originDay; d <= this.endDay; d++) {
      const dow = dayOfWeek(d);
      if (dow === 0 || dow === 6) rects.push({ x: this.dayToX(d), width: this.pixelsPerDay });
    }
    return rects;
  }

  headerCells() {
    const a = this.originDay;
    const b = this.endDay;
    const cell = (label, s, e, extra = {}) => {
      const cs = Math.max(s, a);
      const ce = Math.min(e, b);
      return { label, start: cs, end: ce, x: this.dayToX(cs), width: (ce - cs + 1) * this.pixelsPerDay, ...extra };
    };

    const months = [];
    let { year, month } = ymd(a);
    for (;;) {
      const start = dayFromYMD(year, month, 1);
      if (start > b) break;
      const ny = month === 11 ? year + 1 : year;
      const nm = month === 11 ? 0 : month + 1;
      months.push({ year, month, start, end: dayFromYMD(ny, nm, 1) - 1 });
      year = ny;
      month = nm;
    }

    if (this.scale === 'month') {
      const years = [];
      for (let y = ymd(a).year; y <= ymd(b).year; y++) {
        years.push(cell(String(y), dayFromYMD(y, 0, 1), dayFromYMD(y + 1, 0, 1) - 1));
      }
      return { top: years, bottom: months.map((m) => cell(MONTHS_SHORT[m.month], m.start, m.end)) };
    }

    const top = months.map((m) => cell(`${MONTHS_LONG[m.month]} ${m.year}`, m.start, m.end));
    const bottom = [];
    if (this.scale === 'day') {
      for (let d = a; d <= b; d++) {
        const dow = dayOfWeek(d);
        bottom.push(cell(String(ymd(d).day), d, d, { weekend: dow === 0 || dow === 6 }));
      }
    } else {
      for (let d = a - ((dayOfWeek(a) + 6) % 7); d <= b; d += 7) {
        bottom.push(cell(String(ymd(d).day), d, d + 6));
      }
    }
    return { top, bottom };
  }
}
```

```js
import { fromDay } from './dates.js';

export const MIN_BAR_WIDTH = 4;

const fmt = (n) => +n.toFixed(2);

export function roundedPath(points, radius) {
  const pts = points.filter((p, i) => i === 0 || p.x !== points[i - 1].x || p.y !== points[i - 1].y);
  let d = `M${fmt(pts[0].x)},${fmt(pts[0].y)}`;
  for (let i = 1; i < pts.length - 1; i++) {
    const p0 = pts[i - 1];
    const p = pts[i];
    const p1 = pts[i + 1];
    const l0 = Math.hypot(p.x - p0.x, p.y - p0.y);
    const l1 = Math.hypot(p1.x - p.x, p1.y - p.y);
    const r = Math.min(radius, l0 / 2, l1 / 2);
    if (r <= 0) {
      d += ` L${fmt(p.x)},${fmt(p.y)}`;
      continue;
    }
    const ax = p.x + ((p0.x - p.x) / l0) * r;
    const ay = p.y + ((p0.y - p.y) / l0) * r;
    const bx = p.x + ((p1.x - p.x) / l1) * r;
    const by = p.y + ((p1.y - p.y) / l1) * r;
    d += ` L${fmt(ax)},${fmt(ay)} Q${fmt(p.x)},${fmt(p.y)} ${fmt(bx)},${fmt(by)}`;
  }
  const last = pts[pts.length - 1];
  if (pts.length > 1) d += ` L${fmt(last.x)},${fmt(last.y)}`;
  return d;
}

export function routeLink(pa, ea, pb, eb, gap, rowHeight) {
  const dirA = ea === 'end' ? 1 : -1;
  const dirB = eb === 'end' ? 1 : -1; // côté d'où le lien arrive sur B
  if (dirA === dirB) {
    const xv = dirA === 1 ? Math.max(pa.x, pb.x) + gap : Math.min(pa.x, pb.x) - gap;
    return [pa, { x: xv, y: pa.y }, { x: xv, y: pb.y }, pb];
  }
  const x3 = pb.x + dirB * gap;
  if (dirA * (x3 - pa.x) >= gap) {
    return [pa, { x: x3, y: pa.y }, { x: x3, y: pb.y }, pb];
  }
  const x1 = pa.x + dirA * gap;
  const ym = pa.y + (pb.y >= pa.y ? 1 : -1) * (rowHeight / 2);
  return [pa, { x: x1, y: pa.y }, { x: x1, y: ym }, { x: x3, y: ym }, { x: x3, y: pb.y }, pb];
}

const LINK_EDGES = {
  FS: ['end', 'start'],
  SS: ['start', 'start'],
  FF: ['end', 'end'],
  SF: ['start', 'end'],
};

export function computeLayout(model, ts, metrics, state = {}) {
  const { rowHeight, barHeight, headerHeight, tableWidth, dateColWidth, indent, linkGap, linkRadius } = metrics;
  const rowsInfo = model.visibleRows();
  const width = tableWidth + ts.totalWidth;
  const height = headerHeight + rowsInfo.length * rowHeight;

  const shift = (cell) => ({ ...cell, x: cell.x + tableWidth });
  const cells = ts.headerCells();
  const header = { top: cells.top.map(shift), bottom: cells.bottom.map(shift) };
  const weekends = ts.weekendRects().map(shift);
  const gridLines = header.bottom.map((c) => c.x);
  const today =
    state.today !== undefined && state.today >= ts.originDay && state.today <= ts.endDay
      ? { x: tableWidth + ts.dayToX(state.today) + ts.pixelsPerDay / 2 }
      : null;

  const rows = [];
  const bars = [];
  const tableRows = [];
  rowsInfo.forEach(({ id, depth }, i) => {
    const t = model.getTask(id);
    const group = model.isGroup(id);
    const rowTop = headerHeight + i * rowHeight;
    const y = rowTop + (rowHeight - barHeight) / 2;
    const alt = i % 2 === 1;
    const selected = state.selectedId === id;
    let kind = 'task';
    let x;
    let w;
    if (group) {
      kind = 'group';
    } else if (t.milestone) {
      kind = 'milestone';
    }
    if (kind === 'milestone') {
      w = barHeight;
      x = tableWidth + ts.dayToX(t.start) + ts.pixelsPerDay / 2 - w / 2;
    } else {
      x = tableWidth + ts.dayToX(t.start);
      w = Math.max(ts.barWidth(t.start, t.end), MIN_BAR_WIDTH);
    }
    const progress = model.progressOf(id);
    const startLabel = fromDay(t.start);
    const endLabel = fromDay(t.end);
    rows.push({ id, y: rowTop, alt });
    bars.push({
      id,
      kind,
      x,
      y,
      width: w,
      height: barHeight,
      progress,
      progressWidth: kind === 'milestone' ? 0 : w * progress,
      name: t.name,
      label: `${t.name} (${startLabel} → ${endLabel})`,
      className: t.className,
      collapsed: group && t.collapsed,
      selected,
    });
    tableRows.push({
      id,
      y: rowTop,
      depth,
      name: t.name,
      startLabel,
      endLabel,
      group,
      collapsed: group && t.collapsed,
      alt,
      selected,
    });
  });

  const barById = new Map(bars.map((b) => [b.id, b]));
  const visibleBar = (id) => {
    let cur = id;
    while (cur !== null && !barById.has(cur)) cur = model.getTask(cur).parentId;
    return cur === null ? null : barById.get(cur);
  };
  const anchor = (bar, edge) => ({ x: edge === 'start' ? bar.x : bar.x + bar.width, y: bar.y + bar.height / 2 });

  const links = [];
  for (const link of model.links) {
    const a = visibleBar(link.from);
    const b = visibleBar(link.to);
    if (!a || !b || a === b) continue;
    const [ea, eb] = LINK_EDGES[link.type];
    const points = routeLink(anchor(a, ea), ea, anchor(b, eb), eb, linkGap, rowHeight);
    links.push({
      id: link.id,
      type: link.type,
      fromId: a.id,
      toId: b.id,
      points,
      d: roundedPath(points, linkRadius),
      selected: state.selectedLinkId === link.id,
    });
  }

  return {
    width,
    height,
    metrics,
    rowHeight,
    headerHeight,
    header,
    rows,
    weekends,
    gridLines,
    today,
    bars,
    links,
    table: { width: tableWidth, nameW: tableWidth - 2 * dateColWidth, dateColWidth, indent, rows: tableRows },
  };
}
```

```js
const NS = 'http://www.w3.org/2000/svg';

export function svgEl(name, attrs = {}, text) {
  const e = document.createElementNS(NS, name);
  for (const [k, v] of Object.entries(attrs)) {
    if (v !== undefined && v !== null && v !== false) e.setAttribute(k, v === true ? '' : String(v));
  }
  if (text !== undefined) e.textContent = text;
  return e;
}

const cls = (...names) => names.filter(Boolean).join(' ');

export function readMetrics(el) {
  const cs = getComputedStyle(el);
  const num = (name, fallback) => {
    const v = parseFloat(cs.getPropertyValue(name));
    return Number.isFinite(v) ? v : fallback;
  };
  return {
    rowHeight: num('--gantt-row-height', 32),
    barHeight: num('--gantt-bar-height', 18),
    headerHeight: num('--gantt-header-height', 48),
    tableWidth: num('--gantt-table-width', 360),
    dateColWidth: num('--gantt-date-col-width', 84),
    indent: num('--gantt-indent', 16),
    linkGap: num('--gantt-link-gap', 10),
```

```js
import { GanttModel } from './model.js';
import { Timescale, SCALES } from './timescale.js';
import { computeLayout, renderSVG, readMetrics } from './renderer.js';

let uidCounter = 0;

function todayDay() {
  const n = new Date();
  return Math.floor(Date.UTC(n.getFullYear(), n.getMonth(), n.getDate()) / 86400000);
}

export class Gantt {
  #listeners = new Map();

  constructor(el, options = {}) {
    const scale = options.scale ?? 'week';
    if (!SCALES.includes(scale)) throw new Error(`Échelle inconnue : "${scale}"`);
    this.root = el;
    this.root.classList.add('gantt-root');
    this.scroller = document.createElement('div');
    this.scroller.className = 'gantt-scroll';
    this.scroller.tabIndex = 0;
    this.root.replaceChildren(this.scroller);
    this.uid = `gantt${++uidCounter}`;
    this.readonly = options.readonly === true;
    this.scale = scale;
    this.model = new GanttModel({ tasks: options.tasks, links: options.links });
    this.state = { selectedId: null, selectedLinkId: null };
    this.scroller.addEventListener('scroll', () => this.applySticky(), { passive: true });
    this.refresh();
  }

  on(name, fn) {
    if (!this.#listeners.has(name)) this.#listeners.set(name, new Set());
    this.#listeners.get(name).add(fn);
    return () => this.#listeners.get(name).delete(fn);
  }

  emit(name, detail = {}) {
    for (const fn of this.#listeners.get(name) ?? []) fn(detail);
  }

  #buildTimescale() {
    let min = Infinity;
    let max = -Infinity;
    for (const t of this.model.tasks) {
      if (t.start < min) min = t.start;
      if (t.end > max) max = t.end;
    }
    if (min === Infinity) min = max = todayDay();
    const originDay = min - 7;
    const endDay = Math.max(max + 14, originDay + 30);
    return new Timescale({ scale: this.scale, colWidths: this.metrics.colWidths, originDay, endDay });
  }

  refresh() {
    this.metrics = readMetrics(this.root);
    this.timescale = this.#buildTimescale();
    this.render();
  }

  render({ model = this.model, dragId = null } = {}) {
    this.layout = computeLayout(model, this.timescale, this.metrics, { ...this.state, today: todayDay() });
    const svg = renderSVG(this.layout, { uid: this.uid, readonly: this.readonly, dragId });
    const { scrollLeft, scrollTop } = this.scroller;
    this.scroller.replaceChildren(svg);
    this.scroller.scrollLeft = scrollLeft;
    this.scroller.scrollTop = scrollTop;
    this.svg = svg;
    this.applySticky();
  }

  applySticky() {
    if (!this.svg) return;
    const { scrollLeft, scrollTop } = this.scroller;
    for (const g of this.svg.querySelectorAll('[data-sticky]')) {
      const mode = g.dataset.sticky;
      const x = mode.includes('x') ? scrollLeft : 0;
      const y = mode.includes('y') ? scrollTop : 0;
      g.setAttribute('transform', `translate(${x},${y})`);
    }
  }

  setScale(scale) {
    if (!SCALES.includes(scale)) throw new Error(`Échelle inconnue : "${scale}"`);
    if (scale === this.scale) return;
    const view = (this.scroller.clientWidth - this.metrics.tableWidth) / 2;
    const centerDay = this.timescale.xToDay(this.scroller.scrollLeft + view);
    this.scale = scale;
    this.refresh();
    this.scroller.scrollLeft = Math.max(0, this.timescale.dayToX(centerDay) - view);
    this.applySticky();
    this.emit('scale', { scale });
  }

  select(id, linkId = null) {
    this.state.selectedId = id;
    this.state.selectedLinkId = linkId;
    for (const n of this.svg.querySelectorAll('.is-selected')) n.classList.remove('is-selected');
    if (id) {
      for (const n of this.svg.querySelectorAll('[data-selectable]')) {
        if (n.dataset.id === id) n.classList.add('is-selected');
      }
    }
    if (linkId) {
      for (const n of this.svg.querySelectorAll('.gantt-link')) {
        if (n.dataset.linkId === linkId) n.classList.add('is-selected');
      }
    }
    this.emit('select', { id, linkId });
  }

  commit(type, detail, mutate) {
    const result = mutate(this.model);
    if (result && result.ok === false) {
      this.emit('invalid', { reason: result.reason });
      this.render();
      return result;
    }
    this.emit('change', { type, ...detail });
    this.refresh();
    return result ?? { ok: true };
  }

  getData() {
    return this.model.getData();
  }

  setData(data) {
    const model = new GanttModel(data); // lève avant de toucher à l'état courant
    this.model = model;
    this.state = { selectedId: null, selectedLinkId: null };
    this.refresh();
  }
}
```

```js
import { SCALES } from './timescale.js';
import { svgEl } from './renderer.js';
import { fromDay } from './dates.js';

const DRAG_THRESHOLD = 3;

export function attachInteractions(g) {
  const root = g.scroller;
  let drag = null;
  let lastWheel = 0;

  const local = (e) => {
    const r = g.svg.getBoundingClientRect();
    return { x: e.clientX - r.left, y: e.clientY - r.top };
  };

  function showTip(text, p) {
    const overlay = g.svg.querySelector('.gantt-overlay');
    const w = text.length * 6.2 + 12;
    overlay.replaceChildren(
      svgEl('rect', { class: 'gantt-tip-bg', x: p.x + 12, y: p.y - 30, width: w, height: 20 }),
      svgEl('text', { class: 'gantt-tip-text', x: p.x + 18, y: p.y - 20, dy: '0.35em' }, text),
    );
  }

  function startDrag(kind, id, e) {
    const base = g.model.clone();
    drag = {
      kind,
      id,
      base,
      bar: g.layout.bars.find((b) => b.id === id),
      startX: e.clientX,
      moved: false,
      mutate: null,
      pointerId: e.pointerId,
    };
    root.setPointerCapture(e.pointerId);
  }

  function onPointerDown(e) {
    if (e.button !== 0) return;
    const hit = e.target.closest?.('[data-role]');
    if (!hit) {
      if (g.state.selectedId || g.state.selectedLinkId) g.select(null, null);
      return;
    }
    const role = hit.dataset.role;
    const id = hit.dataset.id;
    switch (role) {
      case 'chevron':
        g.commit('collapse', { id }, (m) => m.toggleCollapsed(id));
        break;
      case 'link':
        g.select(null, hit.dataset.linkId);
        break;
      case 'bar':
        g.select(id, null);
        if (!g.readonly) startDrag('move', id, e);
        break;
      case 'handle-start':
      case 'handle-end':
      case 'handle-progress':
        g.select(id, null);
        if (!g.readonly) startDrag(role, id, e);
        break;
      case 'cell-name':
      case 'cell-start':
      case 'cell-end':
        g.select(id, null);
        break;
      default:
        break;
    }
  }

  function previewMutation(e) {
    const ppd = g.timescale.pixelsPerDay;
    const dx = e.clientX - drag.startX;
    const t0 = drag.base.getTask(drag.id);
    const id = drag.id;
    if (drag.kind === 'move') {
      const delta = Math.round(dx / ppd);
      drag.mutate = (m) => m.moveTask(id, delta);
    } else if (drag.kind === 'handle-start') {
      const day = t0.start + Math.round(dx / ppd);
      drag.mutate = (m) => m.resizeTask(id, 'start', day);
    } else if (drag.kind === 'handle-end') {
      const day = t0.end + Math.round(dx / ppd);
      drag.mutate = (m) => m.resizeTask(id, 'end', day);
    } else {
      const p = (local(e).x - drag.bar.x) / drag.bar.width;
      drag.mutate = (m) => m.setProgress(id, p);
    }
  }

  function onPointerMove(e) {
    if (!drag) return;
    if (drag.kind === 'link') {
      moveLink(e);
      return;
    }
    if (!drag.moved && Math.abs(e.clientX - drag.startX) < DRAG_THRESHOLD) return;
    drag.moved = true;
    previewMutation(e);
    const work = drag.base.clone();
    drag.mutate(work);
    g.render({ model: work, dragId: drag.id });
    const t = work.getTask(drag.id);
    const text = drag.kind === 'handle-progress'
      ? `${Math.round(t.progress * 100)} %`
      : `${fromDay(t.start)} → ${fromDay(t.end)}`;
    showTip(text, local(e));
  }

  function onPointerUp(e) {
    if (!drag) return;
    const d = drag;
    drag = null;
    try {
      root.releasePointerCapture(e.pointerId);
    } catch {
      /* capture déjà relâchée */
    }
    if (d.kind === 'link') {
      finishLink(d);
      return;
    }
    if (!d.moved) return;
    const type = d.kind === 'move' ? 'move' : d.kind === 'handle-progress' ? 'progress' : 'resize';
    g.commit(type, { id: d.id }, d.mutate);
  }

  function onKeyDown(e) {
    if (e.key === 'Escape' && drag) {
      drag = null;
```

```js
const INLINE_PROPS = [
  'fill', 'fill-opacity', 'stroke', 'stroke-width', 'stroke-opacity', 'stroke-linejoin', 'stroke-linecap',
  'stroke-dasharray', 'opacity', 'font-family', 'font-size', 'font-weight', 'font-style', 'text-anchor', 'rx', 'ry',
];

const DEFAULT_PDF_LIBS = {
  jspdf: 'https://cdn.jsdelivr.net/npm/jspdf@2.5.1/dist/jspdf.umd.min.js',
  svg2pdf: 'https://cdn.jsdelivr.net/npm/svg2pdf.js@2.2.3/dist/svg2pdf.umd.min.js',
};

export function buildStandaloneSVG(svg) {
  const clone = svg.cloneNode(true);
  const originals = [svg, ...svg.querySelectorAll('*')];
  const clones = [clone, ...clone.querySelectorAll('*')];
  const toRemove = [];
  originals.forEach((o, i) => {
    const c = clones[i];
    if (o.getAttribute('data-export') === 'skip') {
      toRemove.push(c);
      return;
    }
    const cs = getComputedStyle(o);
    if (cs.display === 'none') {
      toRemove.push(c);
      return;
    }
    for (const prop of INLINE_PROPS) {
      let value = cs.getPropertyValue(prop);
      if (!value) continue;
      if (prop === 'rx' || prop === 'ry') {
        value = value.replace(/px$/, '');
        if (value === 'auto') continue;
      }
      c.setAttribute(prop, value);
    }
  });
  for (const node of toRemove) node.remove();
  for (const g of clone.querySelectorAll('[data-sticky]')) g.removeAttribute('transform');
  clone.querySelector('.gantt-overlay')?.replaceChildren();

  const bg = getComputedStyle(svg).backgroundColor;
  if (bg && bg !== 'rgba(0, 0, 0, 0)' && bg !== 'transparent') {
    const rect = document.createElementNS('http://www.w3.org/2000/svg', 'rect');
    rect.setAttribute('width', clone.getAttribute('width'));
    rect.setAttribute('height', clone.getAttribute('height'));
    rect.setAttribute('fill', bg);
    clone.insertBefore(rect, clone.firstChild);
  }
  return clone;
}

export function serializeSVG(el) {
  return `<?xml version="1.0" encoding="UTF-8"?>\n${new XMLSerializer().serializeToString(el)}`;
}

export function downloadBlob(blob, filename) {
  const url = URL.createObjectURL(blob);
  const a = Object.assign(document.createElement('a'), { href: url, download: filename });
  document.body.append(a);
  a.click();
  a.remove();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}

function loadScript(url) {
  return new Promise((resolve, reject) => {
    const s = document.createElement('script');
    s.src = url;
    s.onload = resolve;
    s.onerror = () => reject(new Error(`Impossible de charger ${url}`));
    document.head.append(s);
  });
}

export async function exportPDFBlob(svg, libs = {}) {
  const urls = { ...DEFAULT_PDF_LIBS, ...libs };
  try {
    if (!window.jspdf) await loadScript(urls.jspdf);
    if (!window.svg2pdf) await loadScript(urls.svg2pdf);
  } catch (e) {
    throw new Error(`Export PDF indisponible : ${e.message}`);
  }
  const { jsPDF } = window.jspdf;
  const clone = buildStandaloneSVG(svg);
  const w = Number(clone.getAttribute('width'));
  const h = Number(clone.getAttribute('height'));
  const host = document.createElement('div');
  host.style.cssText = 'position:fixed;left:-100000px;top:0';
  host.append(clone);
  document.body.append(host);
  try {
    const doc = new jsPDF({ orientation: w >= h ? 'landscape' : 'portrait', unit: 'px', format: [w, h], hotfixes: ['px_scaling'] });
    const opts = { x: 0, y: 0, width: w, height: h };
    if (typeof doc.svg === 'function') await doc.svg(clone, opts);
    else await (window.svg2pdf.svg2pdf ?? window.svg2pdf)(clone, doc, opts);
    return doc.output('blob');
  } finally {
    host.remove();
  }
}
```

````markdown
      { id: 'b', name: 'Réalisation', start: '2026-10-12', end: '2026-10-20' },
      { id: 'm', name: 'Livraison', start: '2026-10-21', milestone: true },
    ],
    links: [
      { from: 'a', to: 'b', type: 'FS' },
      { from: 'b', to: 'm', type: 'FS', lag: 0 },
    ],
  });
</script>
```

Les ES modules exigent un serveur HTTP : `python3 -m http.server 8000`, puis `http://localhost:8000/demo/index.html`.

## Données

**Tâche** : `id` (obligatoire), `name`, `start` et `end` (`AAAA-MM-JJ`, fin incluse, obligatoires sauf pour un groupe), `progress` (0 à 1), `parentId`, `collapsed`, `milestone` (jalon : `end` facultatif), `className`.
Une tâche qui a des enfants est un **groupe** : ses dates sont calculées à partir de ses enfants.

**Lien** : `from`, `to`, `type` (`FS`, `SS`, `FF`, `SF`), `lag` (jours, négatif = avance), `id` facultatif.

| Type | Contrainte sur la cible B |
|---|---|
| FS | `start(B) ≥ end(A) + 1 + lag` |
| SS | `start(B) ≥ start(A) + lag` |
| FF | `end(B) ≥ end(A) + lag` |
| SF | `end(B) ≥ start(A) - 1 + lag` |

Planification en avant : une tâche n'est jamais avancée, seulement repoussée. Un lien vers un groupe décale tout le groupe. Les cycles et les liens entre un groupe et un de ses descendants sont refusés. Un import invalide lève une exception avec un message précis.

## API

```js
const g = new Gantt(el, { tasks, links, scale, readonly, pdfLibs });
g.on('change' | 'select' | 'invalid' | 'scale', handler); // retourne une fonction de désabonnement
g.setScale('month');
g.getData();            // { tasks, links } au format JSON
g.setData(data);        // remplace le planning (lève avant toute modification si invalide)
g.exportSVG(filename?); // télécharge et retourne la chaîne SVG ; filename = null : pas de téléchargement
g.exportJSON(filename?);
await g.exportPDF(filename?);
g.print();
g.destroy();
```

## Interactions

Glisser une barre (déplace), ses bords (redimensionne), le triangle sous la barre (progression) ; glisser une ancre ronde vers une autre barre (crée un lien, le type dépend des ancres) ; clic sur un lien puis `Suppr` ; chevron pour replier ; double-clic sur une cellule du tableau pour éditer ; `Ctrl`/`Cmd` + molette pour zoomer ; `Échap` annule un glissement.
````
